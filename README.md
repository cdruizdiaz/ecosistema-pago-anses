# Ecosistema de Pago ANSES

Diagrama interactivo del circuito de pago de jubilaciones y pensiones de ANSES: actores (ANSES, BCRA, Banco, Beneficiario), dirección de los archivos y flujos de dinero, acciones del beneficiario y controles. Cada flecha y cada recuadro se puede tocar para ver su explicación, el momento, el archivo/formato y la fuente.

Los pasos **1–9** siguen el orden del ciclo normal de pago; los que empiezan con **E** son eventuales (solo en ciertos casos).

## Ver el diagrama

Abrí `index.html` en cualquier navegador, o publicalo en GitHub Pages (abajo).

## Publicar en GitHub Pages

1. Subí `index.html` a la raíz del repositorio.
2. **Settings → Pages** → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)` → **Save**.
3. En ~1 minuto queda disponible en `https://USUARIO.github.io/REPO/`.

## Fuentes

Elaborado a partir del Anexo I – Procedimiento de Pago de Prestaciones de la Seguridad Social (ANSES), la Comunicación BCRA "A" 6386 y la Resolución ANSES 132/2023 (texto actualizado, que consolida las Res. 151/2023 y 1250/2024). Los diseños de registro byte a byte están en el Anexo II (Diseños de Registros).
